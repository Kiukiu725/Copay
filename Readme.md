# Copay — 智能夾錢與海外旅遊分帳神器 💰✈️

Copay 是一個專為朋友聚會、日常夾租以及海外旅行而設的 Web App。透過極簡的 UI 設計與實時雲端同步，讓用戶可以輕鬆記錄開支、處理多國貨幣轉換及複雜的拆帳邏輯。

## 🌟 核心產品線與功能

### 1. Copay Lite (免費日常版)
- **純本地貨幣 (HKD) 記帳**：適合日常食飯、買餸、夾租。
- **無縫極速平分**：一鍵新增開支，自動計算各人應付/應收金額。
- **免費額度**：新用戶預設獲得 1 個免費房間額度，無限次新增單據。

### 2. Copay Travel (Pro 版 - HK$38 早鳥買斷)
- **多幣別實時匯率**：支援 15 國外幣記帳，自動擷取即時匯率轉換。
- **公數錢包 (Common Pool)**：支援設定「公數」，自動防超支計算。
- **進階拆帳邏輯**：支援不等額微調（例如：某人不飲酒少付 $50）。
- **信用卡手續費計算**：一鍵加入自訂信用卡海外簽帳手續費。
- **報表匯出**：一鍵匯出完整 CSV 試算表及 IG Story 圓餅圖消費報告。

## 🛠️ 技術棧 (Tech Stack)
本專案目前採用**單一檔案 (Single-File) 架構**進行開發與部署，以達到最輕量化的管理：
- **前端框架**: React 18 (經 CDN 引入)
- **編譯器**: Babel Standalone (瀏覽器端實時編譯 JSX)
- **樣式**: Tailwind CSS (經 CDN 引入)
- **後端與資料庫**: Firebase Realtime Database (Compat SDK)
- **部署**: GitHub Pages (PWA Ready)

## 🚀 部署與執行
本專案無需複雜的 Node.js/NPM 建置流程。
1. 將專案 Clone 到本地。
2. 直接用瀏覽器打開 `index.html` 即可運行。
3. 若需部署，只需將 `index.html` 及相關靜態資源 (`Copay.png` 等) 推送至 GitHub Pages 即可。
